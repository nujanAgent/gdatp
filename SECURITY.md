# Security

## Reporting a problem in GDatp

Report it privately through GitHub: the repository's **Security** tab, then **Report a vulnerability**. Please do not
open a public issue for it. Say which version of GDatp and which phone and Android version you used, the steps that
show the problem, and what someone could do with it. The report is answered there, and a fix is released before the
details are made public.

Only the latest release is fixed.

In scope: the connection and connected-apps screens, the grants and the check of which app is calling, the tools'
access to projects and files, running code inside the editor, the running game's helper and its token, and any way
another app on the phone can reach GDatp's tools without your consent.

## A problem in Godot itself

A problem that Godot's own editor or engine has too goes to the Godot security team, as Godot's policy describes:
https://github.com/godotengine/godot/security/policy.
